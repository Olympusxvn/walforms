Verify any form

Paste a form's Sui object ID. WalForms will fetch every submission, re-verify each hash, and recompute the Merkle root locally — then compare it to what's on-chain. No wallet needed.

The form ID is the Sui object ID created when the form was saved in the builder (also visible in the shareable form.html?id=… URL).
